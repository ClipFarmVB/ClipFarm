**Epic:** Virtual clips over a mezzanine proxy. The visible payoff.

(a) **Roaming scrub:** scrubber spans the full game; the clip window is a highlighted band; user can seek anywhere in the match (one proxy file, pure playback). (b) **Instant trim:** dragging a handle re-seeks the proxy live (iPhone-editor feel); release saves via the CF-52 PATCH — no spinner, subtle "saved" tick. (c) Polish: keyboard nudge (±0.5s on handles); download button reflects cache staleness after a trim. Stay within the current component structure — this is not the full UI revamp.

**Acceptance:** from any clip you can scrub the entire game; handle drag previews live and save is instant; a trimmed clip's next download re-materializes correctly.

**Depends:** CF-51 + CF-52.
